# Mental Health Tracker

A Django-based web application to help users track their mental health journey, manage daily mood entries, and access helpful resources.

## Project Purpose

Help users monitor their mental health, track moods, and access reliable resources.

## Target Audience

Anyone interested in mental health tracking and wellness.

## Features

- Mood tracking
- Resource library
- User authentication
- Data visualization

## Technologies Used

- Django 6.0.1
- Python 3.14
- SQLite
- Bootstrap 5

## Installation & Setup

1. Clone the repository
2. Create a virtual environment
3. Install dependencies
4. Run migrations
5. Start the server

## Usage

Register, log moods, view trends, and access resources.
